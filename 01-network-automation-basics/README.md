# 01 - Network Automation Basics

This module introduces the fundamentals of network automation using Python.

## What we will learn

- What is network automation?
- Why Python is useful for network engineers
- Python environment setup
- Virtual environments
- Installing Netmiko
- Establishing an SSH connection
- Executing network commands
- Handling credentials securely
- Error handling
- Logging
- Reusable automation functions
- Automating multiple devices

## Learning path

1. Environment Setup
2. First Network Connection
3. Secure Credentials
4. Error Handling
5. Logging
6. Reusable Functions
7. Multiple Devices

## Prerequisites

Basic Python knowledge is helpful but not mandatory.

You should have:

- Python 3.11+
- Git
- A code editor such as VS Code
- Access to a network lab/device for practical execution
